A hands-on course in PostgreSQL 18 for developers who already write SQL. You will learn what the server actually is — databases, schemas, roles, privileges — then how the planner, transactions and locks behave, and finally how to run it. Every lesson has a live playground in your browser and, where it matters, exercises that run against a PostgreSQL 18 container on your own machine.

Start here

Do the setup once. It takes about ten minutes: install Docker, run ./pg up, and the course database is ready. You do not need to install PostgreSQL itself.

How the course works

Read a lesson in order; each one builds on the previous. Run the small SQL examples as you read them, either in the playground on the page or in ./pg psql. Then do the three exercises at the end. Each exercise is a file in your local copy of the repository. You edit it and run ./pg check, and the checker tells you whether your answer does what the task asks.
